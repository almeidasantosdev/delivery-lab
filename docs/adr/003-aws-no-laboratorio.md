# AWS neste laboratorio

O Terraform deste repositorio provisiona uma rede pequena, uma EC2 e um bucket S3 na AWS. A conta de estudo combina com o que o curriculo ja cita: EC2 e S3.

Os produtos da Korven Lab continuam no Render. Render publica aplicacao com menos pecas moveis. Este laboratorio existe para mostrar infraestrutura descrita em codigo, que e outra evidencia. A EC2 recebe o Docker no primeiro boot. Publicar a imagem e liga-la a instancia fica como passo seguinte, com registro e segredo configurados de proposito.
